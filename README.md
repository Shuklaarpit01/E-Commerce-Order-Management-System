## 📌 Project Overview

The **E-Commerce Order Management System** is a SQL-based database project designed to manage online shopping operations efficiently.

It helps store and manage customer details, product information, categories, orders, payments, and shipping records using MySQL.

This project demonstrates practical SQL concepts through real-world e-commerce scenarios.

## 🎯 Project Objectives

- Create and manage an e-commerce database.
- Store customer and product information.
- Track customer orders and payments.
- Manage shipping and delivery details.
- Perform sales and revenue analysis.
- Practice advanced SQL queries.

## 🗂️ Database Structure

The project contains **7 main tables**:

| Table Name | Description |
|---|---|
| Categories | Stores product categories |
| Products | Stores product details and stock |
| Customers | Stores customer information |
| Orders | Maintains customer orders |
| Order_Items | Stores ordered product details |
| Payments | Tracks payment information |
| Shipping | Tracks shipping and delivery |
